# Mouse Control App with Area Selection

A simple Python application using `tkinter` and `pyautogui` to allow users to select areas on the screen and automatically click the selected areas.

## Features

- **Area Selection**: Allows the user to select multiple rectangular areas on the screen.
- **Reset Selection**: Provides the option to reset the selected areas and start over.
- **Click Selected Areas**: Automatically clicks the center of the selected areas after they have been selected.
- **Full-Screen Selection**: The area selection window is fullscreen with a semi-transparent background.
- **Smooth Mouse Movement**: The app moves the mouse smoothly to the center of the selected area before clicking.

## Prerequisites

Ensure you have the following Python libraries installed:

- `tkinter` (for the GUI)
- `pyautogui` (for mouse control)
- `time` (for handling delays)
